# GachiTa 개발 진행 상태

기준일 2026-11-16
현재 작업 브랜치 `feature/kakao-map`

## 지도·위치 선택 시연 UI

- Android Expo Go에서 카카오 지도를 표시한다.
- 중앙 고정 핀으로 출발지를 고르고 도로명 주소와 건물명 후보를 구분해 표시한다.
- 도착지는 장소 검색 결과 또는 지도에서 직접 선택하고, 지도에서 조정할 수 있다.
- 도착지 검색 화면은 `src/components/maps/PlaceSearchPanel.tsx`로 분리해 검색 결과 선택과 지도에서 직접 선택을 제공한다.
- 도착지를 확정하면 출발·도착 핀을 한 지도에 맞춰 표시한다.
- 실제 경로 좌표를 받으면 경로선을 그릴 수 있도록 지도 부분을 준비했다. 현재는 서버 데이터가 없어 경로선과 예상 시간을 표시하지 않는다.

## 확인 및 팀 공유 항목

- 사용자가 Android Expo Go에서 출발·도착 선택과 두 핀 표시를 확인했다.
- 전체 TypeScript 검사는 기존 `src/components/app-tabs.web.tsx:38` 오류로 실패한다. ESLint 설정이 없어 lint 검사는 진행되지 않았다.

### 휴대폰 검증 대기

- ‘다시 검색’과 ‘다시 조정’ 버튼의 이번 변경 후 동작은 휴대폰에서 추가 확인이 필요하다.

### 팀 협의 후 연결

- 공통 서버 설정과 `POST /api/v1/maps/route`의 응답 형식·카카오모빌리티 키 관리 방식을 맞춘 뒤 실제 도로 경로와 예상 시간을 연결한다.
- 도착지를 바꾸면 경로와 예상 시간을 다시 조회하도록 연결한다.
- 방 생성 화면으로 출발·도착 좌표를 전달하는 방식은 해당 화면 담당자와 맞춘다.
