# GachiTa 개발 진행 상태

기준일 2026-11-14
현재 브랜치 `feature/taxi-chat`

## 완료한 작업

- 채팅 목록·채팅방과 화면 이동 구현
- 메시지 입력·전송·방별 구분·공백 방지·500자 제한 구현
- 말풍선 폭과 긴 메시지 자동 스크롤 오류 수정
- 마지막 검사에서 테스트 6개와 TypeScript 검사 통과
- 2026-11-14 실제 Android 휴대폰의 Expo Go에서 두 줄 메시지가 입력한 줄바꿈대로 표시되고, 500자 메시지가 화면 폭 안에서 줄바꿈되는 것을 사용자 확인.
- 2026-11-14 실제 Android 휴대폰의 Expo Go에서 500자 메시지 전송 직후, 수동 스크롤 없이 마지막 ‘마지막확인’ 문구가 입력창 위에 표시되는 것을 사용자 확인.

메시지는 시연 데이터로 관리하며 새로고침하면 초기화된다.

## 실행·검사 방법

프로젝트 폴더 `D:\ReactNative\GachiTa`에서 실행한다.

- 패키지 설치 `npm.cmd ci`
- 앱 실행 `npm.cmd start -- --lan`
- 메시지 테스트 `node --test tests/chat.test.cjs`
- 타입 검사 `node node_modules/typescript/bin/tsc --noEmit`

휴대폰은 PC와 같은 Wi-Fi에 연결하고 Expo Go에서 QR 코드를 스캔한다.

## 화면 연결

홈 → 채팅 시연 목록 → 채팅방 → 뒤로 가기

- 홈 `/`
- 채팅 목록 `/chats`
- 채팅방 `/rooms/[roomId]/chat`
